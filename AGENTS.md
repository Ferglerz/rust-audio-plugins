# Damian Channel Strip - Project Rules

## Build and DAW Installation Protocol

When building, bundling, or finishing code changes for this project:
- Always replace/install the release VST3 into the DAW plug-in directory:
  `$HOME/Library/Audio/Plug-Ins/VST3/Damian Channel Strip.vst3`
- Run `./scripts/install.sh` after completing changes so the DAW plug-in is always up to date.
