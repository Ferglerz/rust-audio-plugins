# Yamaha CP-80 physical model

Electric Grand 80 implements this design as a playable CLAP and VST3. The implementation notes include the calibration results, listening comparisons and measurements still needed from hardware. [Implementation and verification](../cp80/README.md)

Target the original 88-key CP-80 in Yamaha's September 1978 service documentation, serial 1001 onward. The proposed instrument is sample-free and plays A0–C8 (MIDI 21–108). Use the stereo jack outputs as the default listening reference so the original Volume control behaves as a player expects. Keep the balanced line outputs available in the offline renderer for comparison. [Yamaha service manual](https://www.synthxl.com/wp-content/uploads/2020/04/Yamaha-CP-80-Service-Manual.pdf) · [Yamaha operating manual](https://ca.yamaha.com/files/download/other_assets/9/322059/CP80E.PDF)

Use Stage 73's independent ngspice comparison and held-out recording comparisons. Use OpenWurli's practice of retaining reference renders when simplifying expensive DSP. The event timing, oscillator math, editor, plugin wrappers and installer have precedents here. The hammer contact, strings, piezo network and electronics belong to the CP-80. ## Mechanical model

Build one persistent mechanical state per key. The schematic specifies one pickup per key, including keys where a single hammer strikes two strings. The first three prototype notes should be **F♯2, G2 and E♭4**. They exercise all three string constructions with a small enough instrument to hear and diagnose every change. [Yamaha parts list, printed pp. 28–31](https://manuals.fdiskc.com/tree/Yamaha/Yamaha%20Electric%20Grand%20Parts%20List%20for%20CP-70%20CP-70B%20CP-80.pdf) · [Pickup wiring](https://www.synthxl.com/wp-content/uploads/2020/04/Yamaha-CP-80-Service-Manual.pdf#page=53)

| Keys | Construction or adjustment | Consequence for the model |
| --- | --- | --- |
| 1–22, A0–F♯2 | One wound string per key | Fit the upper partials and their losses on single strikes. Beating here cannot be attributed to a second unison string. |
| 23–42, G2–D4 | Paired wound strings | Drive both from one hammer. Fit unison spacing, relative excitation and energy exchange from long notes. |
| 43–88, E♭4–C8 | Plain wire, with gauge changes starting at key 43 | Carry the wire-gauge breaks into the key table. Estimate stiffness and loss within each range. |
| 1–73 and 74–88 | The parts list ends the damper heads at key 73, A6 | A6 should stop on release with the pedal up. B♭6 should ring through release. Capture both. |
| Whole keyboard | Six hammer assemblies for keys 1–32, 33–58, 59–71, 72–80, 81–82 and 83–88 | Use the assembly breaks as places to check voicing. Measure how much contact changes at each break. |

The service table gives all 88 tuning offsets. A0 is −23 cents, A4 is 440 Hz and C8 is +35 cents. Enter that table directly. Fit inharmonicity separately from the spacing of partials within each note. The action has a 40 mm hammer blow distance and a 10 mm key dip. Yamaha specifies urethane and artificial leather for the hammers. These constrain the mechanism while leaving hammer mass, stiffness, contact width and losses to be measured or fitted. [Factory tuning table and regulation, pp. 14–16](https://www.synthxl.com/wp-content/uploads/2020/04/Yamaha-CP-80-Service-Manual.pdf#page=14) · [Hammer specification](https://ca.yamaha.com/files/download/other_assets/9/322059/CP80E.PDF)

1. **Strike.** Map MIDI velocity to incoming hammer speed. Solve a finite-width, compression-only contact between a hammer mass and the moving string or pair. The hammer can rebound. Harder playing should change contact duration and attack spectrum as well as level. A restrike acts on the string's existing displacement and velocity.
2. **Ring.** Start with a high-accuracy offline modal string model. Each mode has a frequency set by fundamental and stiffness, a strike-position weight, and a measured loss rate. Couple paired strings at their common support. Compare the partial frequencies, beat periods and early and late decay slopes independently. A modal model makes each of these quantities inspectable. [Bank, Zambon and Fontana, *A Modal-Based Real-Time Piano Synthesizer*](https://home.mit.bme.hu/~bank/publist/taslp-piano/index.html)
3. **Damp.** Apply damper contact to the ringing strings when both key and pedal release them. Measure note-off, pedal catch and restrike at several delays. Test for cross-key mechanical coupling by silently holding an upper note, striking a related bass note and damping the bass. Use the residual at the upper note's partials to set the strength of a passive shared-frame model. Keep electrical bus loading present in both conditions.
4. **Sense.** Start with the dynamic reaction force at the string bearing driving piezo charge. Represent each pickup by a charge source and parallel capacitance, including the load of silent keys. Treat the force projection, sensitivity and capacitance as estimates until measured. A useful bench measurement is pickup-bus impedance versus frequency with the preamp disconnected. A direct recording alone cannot uniquely identify hammer stiffness, piezo sensitivity and circuit gain.

## Electronics and independent checks

Transcribe Yamaha drawing **006806** to an ngspice deck with the printed component identifiers, transistor bias, pot tapers, switch contacts, trims, rails and output loads. Retain the 22 nF mixing capacitor between pickup keys 82 and 83. Drive each side independently during verification. The documented signal path is FET1, the tone network and brilliance switch, FET2/3, the normalled patch loop, FET4/5, then the two optically modulated branches. FET6/7 drive the line transformers. The dual Volume pot feeds the FET9/8 jack buffers. The patch send is a useful observation point after tone shaping and before tremolo. [Overall schematic](https://www.synthxl.com/wp-content/uploads/2020/04/yamaha_cp-80_overal_circuit.pdf) · [Block diagram](https://www.synthxl.com/wp-content/uploads/2020/04/yamaha_cp-80_block_diagram.pdf)

Start the real-time circuit with a reduction of that network around its measured or nominal bias. Retain the free-running RC4558 oscillator, driver and photocell response in the reference. Fit the two gain envelopes, their phase relationship and attack/recovery at slow and fast settings. Opposite modulation phase means the channel levels rise in turn. Preserve audio polarity. Add signal-dependent FET or transformer behavior to the real-time path where hard strikes or chords show a repeatable level-dependent residual.

| Bench check | Proposed acceptance |
| --- | --- |
| Factory input and gain trim | With the six controls fully clockwise, brilliance Medium and tremolo off, Yamaha applies −32 dBm at 500 Hz to board IN. Adjust VR12 for −29.0 ±0.5 dBm at PO. Reproduce the source, load and meter reference before comparing levels. |
| Brilliance and tone | Under service step 10, the 5 kHz targets are −24, −29.5 and −41.5 dBm for High, Medium and Low, each ±1.5 dB. Also run the 50 Hz bass and 5 kHz treble checks in their specified control positions. |
| Output routing and tremolo | Turning Volume down must attenuate both jacks while preserving line level. Verify opposing envelope peaks, nominal 0.8–10 Hz speed range and factory trim limits of under 15% minimum and over 40% maximum modulation. Record both channels together. |
| Real-time circuit reduction | Proposed numerical target of ≤0.25 dB magnitude error against the deck from 40 Hz to 10 kHz at nominal small-signal level, for all brilliance settings and representative pot and load combinations. Compare phase, transient headroom and modulation envelopes separately. |

The first three checks use Yamaha's published settings or limits. The fourth tests the software reduction against the reference circuit. Record uncertain device parameters and loads beside the resulting curves. [Factory adjustments, pp. 11–12](https://www.synthxl.com/wp-content/uploads/2020/04/Yamaha-CP-80-Service-Manual.pdf#page=11) · [Output controls](https://ca.yamaha.com/files/download/other_assets/9/322059/CP80E.PDF)

## Calibration and delivery

1. **Assemble the evidence.** For each key, store string count, winding or gauge, tuning offset, hammer group and damper presence. Give each remaining parameter a unit and source, and mark it as documented, measured, fitted or assumed. Prioritize speaking length, strike position, paired-string detuning, pickup capacitance and hammer-contact duration. Greg Sullivan's four-dynamic CP-80 set with neutral tone controls is a candidate for attack comparisons. Use original, unlooped portions at their recorded pitches. The sampler adds its own tremolo and release behavior. [Sullivan's recording notes](https://www.sullivang.net/yamaha-cp80-electric-grand-instrument-for-gigasamplergigastudio)
2. **Make the three-note comparison.** Record dry stereo outputs at fixed gain, centered EQ, Medium brilliance and tremolo off. Log the instrument, output used, load and tuning. Capture repeated soft, medium and hard strikes, full decays, and releases at known times. Render the same sequence offline. Deliver alternating hardware/model WAVs at one gain per recording session, with per-partial pitch, attack level, beat rate and decay errors. Use repeat-strike scatter to set listening and measurement tolerances. If only edited samples are available, mark the release and pedal comparisons pending direct capture.
3. **Extend to 88 keys.** Interpolate fitted mechanics within construction groups. Reserve complete pitches and a playing dynamic before fitting. Include both sides of the wound/plain, damper and pickup-bus boundaries in the recording set. Compare a bass octave, a quiet repeated chord and a pedal-down arpeggio against the hardware. Publish held-out errors and the worst keys alongside the listening clips. A second instrument can show which differences are voicing or tuning specific.
4. **Deliver the plugin.** Place the proven engine in its own workspace crate with an offline probe, checked-in calibration table and the stock CP-80 panel controls in Pleasant UI. Keep a stereo render path after the shared mono pickup bus. At 44.1, 48 and 96 kHz, check hard treble strikes against a higher-rate reference, sustain and release an 88-key chord, and log worst-block render time at 64-frame buffers on a named machine. Reserve headroom for the host. Verify event timing and both installed CLAP/VST3 bundles through headless hosts using the repository's plugin installer.

The first decision point is the dry three-note A/B plus the independent circuit check. If the single wound string has the wrong attack, investigate hammer contact and pickup response. If the single works and the paired note decays incorrectly, investigate unison tuning and coupling. Expand the keyboard once the same mechanical and circuit parameters explain soft and hard strikes on those notes.
