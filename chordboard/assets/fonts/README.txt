Embedded in Chordboard for SMuFL accidentals and chord quality symbols.
Ordinary letters and numbers use the existing UI font. Measurement and drawing
share the same font stack. The triangle denotes major seventh; + is augmented.
Mapping occurs only in the UI; harmony names and saved state remain unchanged.
